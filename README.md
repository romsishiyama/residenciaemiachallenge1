# residenciaemiachallenge1
Documentação referente à atividade de 7 semanas do primeiro desafio do Programa de Residência em IA, pelo Instituto Eldorado e Puc Campinas.
Com o tema Fake News, realizar análise exploratória de dados usando Google Collab na linguagem de programação Python.
Estudos sobre ferramentas de visualização de dados e algoritmos.
Eleger 3 modelos de treinamento supervisionado e 3 não supervisionado.
Criação de uma plataforma de checagem de fake news, onde o usuário pode colar o link da notícia a ser verificada.
Após enviar para a verificação, a plataforma retorna com os indicadores da notícia ser verdadeira ou falsa de acordo com as métricas.
